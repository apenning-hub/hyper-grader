review guide

Hyper Grader is a rubric-marking app for teachers (Mac and iPad). No account or sign-in. All data stays on the device; the Mac and iPad do not sync. No network is used unless you choose the optional Claude API.

mac

  1. 1 Quick start: File > Import... (Shift-Cmd-O), choose "Hyper Grader demo library.hyper", press Merge. Two demo courses appear with marked students and dates. Click Today at the top of the sidebar: today's plan, List/Board, Delay > Not Today / Push Deadline.
  2. 2 Import a class: File > Import..., choose 2026-11-26T0930_Grades-ARCH_1010.csv. The sheet reports a Canvas gradebook export, 12 students, 2 assignments. Import, then Done. Course ARCH1010 gets two assessments (Test Student is left out).
  3. 3 Rubric: File > Import..., "Project 2 - Pavilion rubric.csv"; it is set to go to Project 2 - Pavilion. Import. (After step 2: imported together with a new class, a rubric is only saved to the Rubrics tab.) Wrong-file check: import "Project 2 - Pavilion rubric assessments.csv" the same way; the sheet says it is for sending marks back. Class list: "Tutorial ST02 class list.csv", choosing the assessment beside "Queue for".
  4. 4 Dates: right-click an assessment > Dates..., set Submitted to a few days ago.
  5. 5 Mark: open Project 2 - Pavilion. Student name starts empty: Next Student (Cmd-]) fills the first name on the class list (Previous: Cmd-[). Click a band per criterion, then High, Mid or Low (arrow keys move bands). Within 2% below a grade boundary, an orange "below ... review" note shows.
  6. 6 Dictate: Record (Cmd-R). macOS asks for Speech Recognition when an assessment first opens and Microphone at the first Record. Dictation is on-device only; if it cannot run, an error says why and you can type in Notes.
  7. 7 Feedback: Generate (Cmd-Return) uses Apple Intelligence on the device. If that is off or unsupported, Generate is dimmed, and its tooltip and Preferences > AI Model show the reason (e.g. "Enable Apple Intelligence in System Settings."). Type feedback in the Feedback box; Next Student (Shift-Cmd-Return) saves it. To read finished feedback, open Studio Report (demo library), person icon, Sana Whitfield.
  8. 8 Student finder (person icon): search, switch; right-click > Delete... asks first.
  9. 9 Canvas: mark two students, then ... menu (top right) > Link to Canvas... Click a box, choose the gradebook export and the rubric assessments file together, press Link. Then ... > Send to Canvas... lists each grade; comments are optional. Export 2 files... saves two CSVs to a folder you pick. Nothing is uploaded.
  10. 10 Rubrics tab (top of sidebar): New Rubric > Build from Scratch. Five steps: Task, Outcomes, Alignment, Levels & Marks, Review. AI drafting needs Apple Intelligence; typing works without.
  11. 11 ... menu: Statistics, Compare Students, Export Grades (CSV); Check Feedback Consistency needs Apple Intelligence. Preferences (Cmd-,): Grade scale, Marking Deadlines.

optional claude api

Preferences > AI Model > Claude API asks "Share Grading Data with Anthropic?" (Allow / Don't Allow). It needs the user's own Anthropic key; none is provided or needed. Student names are not sent.

ipad

The iPad version has no Apple Intelligence feedback, rubric builder or Canvas export.

  1. 1 First launch: Try It with Sample Data (marked students), or Create a Course. Later: + (Cmd-N) New Assessment: choose or create a course, name it, Create.
  2. 2 Add Rubric > Choose a CSV File..., "Project 2 - Pavilion rubric.csv", Add. Top-right ... > Class List... > Import from a File..., "Tutorial ST02 class list.csv", Save.
  3. 3 Tap a band, then High, Mid or Low. Record dictates (same permissions, on-device). Type feedback; Save & Next. The person icon lists students.
  4. 4 Home is the marking plan. On an assessment row, Delay > Set Dates... sets Submitted and fills the plan.
