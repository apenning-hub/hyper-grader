review guide

No account or sign-in is needed. Everything runs on the device, and no network is used unless you choose the optional Claude API. The class, students and marks in these files are fictional.

sample files

Download all four. They use Canvas LMS export formats.

  • 2026-11-26T0930_Grades-ARCH_1010.csv Canvas gradebook export: 12 students in two studio sections, plus Canvas’s Test Student, and two assignments.
  • Project 2 - Pavilion rubric.csv The rubric for Project 2, in Canvas’s rubric layout: 4 criteria, 5 grade bands, 70 points.
  • Project 2 - Pavilion rubric assessments.csv Canvas’s rubric assessments download for Project 2, used by Link to Canvas.
  • Tutorial ST02 class list.csv A plain class list of 6 students, for the iPad or Paste a List.

mac

  1. 1 Import a class. File > Import… (⇧⌘O) and choose 2026-11-26T0930_Grades-ARCH_1010.csv. The review sheet says it found a Canvas gradebook export with 12 students and 2 assignments. Press Import. Course ARCH1010 appears with two assessments; Canvas's Test Student is left out.
  2. 2 Add the rubric. Select "Project 2 - Pavilion" in the sidebar, then File > Import… and choose "Project 2 - Pavilion rubric.csv". "Use for" shows Project 2 - Pavilion. Press Import. To see the wrong-file check, import "Project 2 - Pavilion rubric assessments.csv" the same way: the app explains it is for sending marks back, not a rubric.
  3. 3 Set dates. Right-click Project 2 - Pavilion > Dates… Set Submitted to a few days ago and close. Click Today at the top of the sidebar: the start screen shows today's target, a progress ring and every assessment by urgency. Switch List/Board. Try Delay > Not Today and Delay > Push Deadline.
  4. 4 Mark. Open Project 2 - Pavilion. The first student loads. Click a grade band for each criterion, then High, Mid or Low inside it (arrow keys move between bands). The total and grade update live; a total within 2% below a grade boundary shows an orange "below … review" note.
  5. 5 Dictate. Press Record (⌘R), allow microphone and speech recognition, and speak. Dictation is on-device only.
  6. 6 Generate (⌘↩) writes feedback with Apple Intelligence on the device. It needs Apple Intelligence turned on; otherwise the app says so and you can type feedback directly.
  7. 7 Next student: ⇧⌘↩. Mark two or three students. The person icon opens a searchable student list; right-click a student > Delete… (asks first).
  8. 8 Send to Canvas. In the … menu at the top right of the assessment, choose Link to Canvas… Add the gradebook export and "Project 2 - Pavilion rubric assessments.csv", choose the assignment "Project 2 - Pavilion" and press Link. Then … > Send to Canvas… shows each student's grade and per-criterion comments and saves two CSV files (gradebook import and rubric import). Nothing is uploaded; teachers upload the files to Canvas themselves.
  9. 9 Also: Change > Edit Rubric… (rubric editor); in the … menu, Statistics, Compare Students, Check Feedback Consistency (two or more marked students) and Export Grades (CSV); Preferences (⌘,) for grade bands and marking deadlines.

optional claude api

Preferences > AI Model > Claude API shows a permission prompt explaining what is sent; Don't Allow returns to on-device. It needs the user's own Anthropic API key; none is required to review the app. Student names are replaced with placeholders before anything is sent.

ipad

Use + to create a course and assessment, add the rubric CSV from Files (or paste rows from a spreadsheet), and paste the class list from "Tutorial ST02 class list.csv". Tap a band and a step for each criterion, tap the mic to dictate, and Save & Next. Feedback generation and Canvas export are Mac-only.
