Hyper Grader review files
=========================

Everything here is fictional: the class, the students and the marks. The CSVs use the same layouts as Canvas LMS exports. Nothing needs an account.

Hyper Grader demo library.hyper
  A ready-made library: two demo courses (DEMO 2020 Studio Practice and DEMO 1010 Seminar), three assessments, four marked students, and dates set so the Today plan is never empty. Mac only: File > Import... (Shift-Cmd-O), then Merge. Delete the two demo courses afterwards if you like (right-click a course > Delete Course).

2026-11-26T0930_Grades-ARCH_1010.csv
  Canvas gradebook export: 12 students in two studio sections, plus Canvas's Test Student, and two assignments (Project 1 - Site Study, Project 2 - Pavilion). Mac: File > Import... Creates course ARCH1010 with both assessments and the class as the marking queue. Also used by Link to Canvas.

Project 2 - Pavilion rubric.csv
  The rubric for Project 2, in Canvas's rubric layout: 4 criteria, 5 grade bands, 70 points. Mac: File > Import... (after the gradebook). iPad: Add Rubric > Choose a CSV File...

Project 2 - Pavilion rubric assessments.csv
  Canvas's rubric assessments download for Project 2 (headers and student rows, no marks). Used by Link to Canvas on the Mac. If you import it with File > Import... the app tells you it is for sending marks back.

Tutorial ST02 class list.csv
  A plain class list of 6 students (Student Name, Student ID, Section). Mac: File > Import..., choosing the assessment to queue them for. iPad: Assessment Options > Class List... > Import from a File...

Step-by-step instructions are in the App Review notes.
